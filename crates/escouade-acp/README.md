# escouade-acp

Le client ACP (Agent Client Protocol, version 1) d'[Escouade](https://escouade.dev) : une machine à états qui lit les lignes d'un
agent et répond les éléments de la conversation et les lignes à lui écrire, sans process ni runtime à elle. Elle compile aussi pour
`wasm32-wasip1`.

La référence des plugins : <https://escouade.dev/docs/plugins/api>. Le code est dans [le dépôt d'Escouade](https://github.com/guillaume-gagnaire/escouade),
sous licence GPL-3.0-or-later.
