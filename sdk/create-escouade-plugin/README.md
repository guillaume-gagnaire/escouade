# create-escouade-plugin

`npm create escouade-plugin@latest my-plugin`: a new plugin of [Escouade](https://escouade.dev), a TypeScript program with its tests (`--kind program`), the same in Rust as a WASM module (`--kind rust`) or a declarative theme (`--kind declarative`). `--id` and `--name` give its id and its name.

Documentation: https://escouade.dev/en/docs/plugins/quick-start. MIT license.
